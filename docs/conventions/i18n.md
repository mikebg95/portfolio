# Languages and routes

- English at `/`, Dutch at `/nl/` (SPEC §1.4). A page is ONE file under `src/pages/[...lang]/`
  with `getStaticPaths() { return langPaths(); }` (or `langPaths()` combined with its own params,
  as `projects/[slug].astro` does) and `Props { lang: Lang }`. Never a second copy under `nl/` —
  only `404.astro` has one, because Astro finds the 404 page by name.
- Every internal link is built with `localize(lang, path)` from `src/i18n/paths.ts`; the language
  switch with `alternate(lang, Astro.url.pathname)`. Never write `/nl` by hand.
- Sheet order, numbers and paths: `SHEETS` in `src/i18n/routes.ts`; project detail paths with
  `projectPath(slug)`. Sheet names come from `t(lang).sheets[key]`.
- Strings shared by every page (header, footer, SEO, 404): `const ui = await t(lang)` from
  `src/i18n/content.ts`. Entries: `getLocalized(collection, id, lang)` /
  `getAllLocalized(collection, lang)` (sorted by `order`, else `item`); `sharedId(entry)` is the
  id without its `<lang>/` prefix.
- Unit tests of code that reads `astro:content`: `vi.mock('astro:content', () => fakeAstroContent)`
  from `tests/unit/helpers/content.ts` — the real store is empty under Vitest.
- Dates: `formatMonth` / `formatSpan` from `src/dates.ts` with `ui.dates` (`NOV 2023`, `NOW`);
  never a month name in code. Each language's words are as displayed (EN caps, NL `jun 2026`).
