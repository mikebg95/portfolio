## 2026-10-04 — Fonts vendored in `public/fonts/`, tokens.css committed and Prettier-formatted
Who: agent (PR-4). Why: the woff2 latin subsets were copied once from Fontsource 5.3.0
(`@fontsource-variable/archivo` `archivo-latin-wdth-normal.woff2` = wdth 62–125 + wght 100–900;
`@fontsource/ibm-plex-sans|mono` latin 400/500/600) with their OFL licences, so a build never
needs the network and no font package sits in `node_modules`. Instead of: Fontsource npm deps or
Astro's Fonts API (downloads at build). `src/styles/tokens.css` is committed (typecheck/tests
work on a fresh clone) and regenerated by `dev`/`build`; the generator formats it with Prettier
and a test fails if it is stale. Descriptive tokens resolve as: a range "15–16px" → upper bound
(16px); "56px desktop, 24px phone" → base + `-phone`; breakpoints become `-min`/`-max` (media
queries must still use literals). Preloaded faces: Archivo (display) and Plex Sans 400 (body).

## 2026-10-04 — Shared strings in a `ui` collection; pages once under `src/pages/[...lang]/`
Who: agent (PR-5). Why: CLAUDE.md puts all text in content collections, and header, footer, SEO
and 404 strings belong to no page, so they are one `ui` entry per language (all of copy.md Global,
SEO and 404 at once, so PR-7/9/10/36/37 only read fields, never change the schema) behind
`t(lang)`. Contact targets stay in `profile.contact`; the domain label comes from `SITE_URL`.
Each route is one file under `src/pages/[...lang]/` whose `getStaticPaths` yields `lang`
undefined (→ `/x`) and `nl` (→ `/nl/x`), so a page is never written twice; 404 is the exception
(`src/pages/404.astro` + `src/pages/nl/404.astro`, Astro finds the 404 page by name). URLs are
built by the pure `src/i18n/paths.ts`, not `astro:i18n`, so they are unit-testable. Four placeholder
project entries (P-02…P-05, real slug/code/title/repo) were added so every detail route exists;
PR-21 fills them. Instead of: a TS dictionary of strings, or a page file per language.
