SPECIFICATION
SECURITYThree ordered security chains: public API docs, Actuator behind basic auth, the API behind JWT. Roles read from the token; method security and a custom ownership annotation.
DATAPostgreSQL for users (JPA), MongoDB for items and the audit log.
TESTINGUnit, slice, security and integration tests on Testcontainers.
FRONTENDVue 3, Pinia, Vite; Capacitor builds for iOS and Android.
DELIVERYDocker images for backend, frontend and Keycloak; local, dev and prod profiles.
